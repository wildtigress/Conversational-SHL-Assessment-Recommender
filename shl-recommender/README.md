# SHL Assessment Recommender

A conversational AI agent built with FastAPI that helps hiring managers and recruiters navigate the SHL product catalog to find the right individual test solutions. It takes users from a vague intent to a grounded shortlist of SHL assessments through dialogue.

## Overview
This service exposes a stateless POST `/chat` endpoint that processes conversation history, retrieves relevant assessments using a FAISS vector index, and returns structured recommendations generated by a Groq LLaMA model. It strictly adheres to SHL catalog constraints and prevents hallucinations.

## Features
- **Semantic + Keyword Retrieval:** Uses `sentence-transformers` (`all-MiniLM-L6-v2`) and FAISS for efficient, high-recall retrieval.
- **Conversational Handling:** Can clarify vague queries, recommend specific assessments, refine shortlists based on updated constraints, and compare assessments.
- **Strict Guardrails:** Refuses off-topic questions (e.g., prompt injection, salary info) and verifies every recommended URL against the scraped catalog.
- **Stateless API:** Follows the REST pattern by taking the full conversation history in every request.

## Tech Stack
- **Web Framework:** FastAPI (Uvicorn)
- **LLM Provider:** Groq (llama-3.3-70b-versatile)
- **Retrieval:** FAISS-CPU, SentenceTransformers
- **Scraping:** BeautifulSoup, requests, Playwright

## Prerequisites
- Python 3.10+
- A [Groq API Key](https://console.groq.com/keys)

## Local Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd shl-recommender
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Variables:**
   Create a `.env` file in the root directory and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```

5. **Run the server:**
   ```bash
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

## API Endpoints

### 1. Health Check
`GET /health`
```json
{
  "status": "ok"
}
```

### 2. Chat
`POST /chat`
Accepts a JSON payload with `messages` (the conversation history) and returns a structured response.

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "I am hiring a Java developer"}
  ]
}
```

**Response:**
```json
{
  "reply": "Got it. What seniority level are you looking for?",
  "recommendations": [],
  "end_of_conversation": false
}
```

## Testing
To verify the agent behavior against the required test scenarios, run the included test suite:
```bash
python test_agent.py
```
This runs 6 multi-turn conversational traces verifying clarification, recommendation, refinement, comparison, and refusal behaviors.
